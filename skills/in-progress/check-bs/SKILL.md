# check-bs

Helps to re-think if this is a bullshit or not.

## Process

1. Collect context
2. Analyze the content

- Factuality check; Find ground, supporting details, and more
- Alternative considered, trade-offs implied
- Objection, opposite ideas conceived.

3. Verdict and reason.
